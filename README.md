# EventHub – Event Booking Management System

EventHub is a full-stack web application developed using Python Flask and MySQL that simplifies event management and online booking. The system provides dedicated dashboards for both administrators and users.

Administrators can add, edit, delete, and manage events, view registered users, monitor bookings, and track dashboard statistics. Users can register, log in securely, browse available events, book events, view booking history, and make online payments through Razorpay.

## Features

- User Registration & Secure Login
- Password Hashing
- Admin Dashboard
- User Dashboard
- Add, Edit & Delete Events
- Upload Event Images
- Browse Available Events
- Book Events
- My Bookings
- Dashboard Statistics
- Razorpay Payment Integration
- MySQL Database
- Responsive Bootstrap UI

## Tech Stack

- Python
- Flask
- MySQL
- HTML5
- CSS3
- Bootstrap 5
- Jinja2
- Razorpay Payment Gateway

This project demonstrates a complete event booking workflow with role-based authentication, database integration, and online payment support.
